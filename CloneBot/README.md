### Changes made

- Built the first seven CloneBot UI areas using React, TypeScript, and local mock data.
- Added browser persistence for knowledge review items, reply drafts, calendar events, and assistant/privacy settings.
- Demo data is stored in this browser on this device using localStorage. It is not sent to a server and is not shared with teammates through Git.
- Use the help button in the app and choose **Reset demo data** to restore the original sample content.

The sign-in, file processing, invitations, reply sending, and reminders are still demonstrations; they do not call a backend service.
